ORBCAFE × ORBIS — Modules reference

Continuation of the core reference: pivot & chart visualization, Kanban, planning/Gantt, pad surfaces and agent UI. Same discipline — color and typography only; interactions, drag behavior, streaming and data flow are untouched.

1 — Pivot & chart visualization

Series order: primary → primary-300 → muted → primary-700, then repeat. Grid lines 1px border color, axis labels 11px/500 muted, no chart chrome beyond that. Fills, never bare outlines; no gradients in data marks.

2 — Kanban

Columns on surface, cards on canvas with 1px border and quiet elevation. Drag ghost = 2px primary outline + raised shadow; drop target = 2px primary line. Over-WIP count switches the badge to error color. Drag mechanics unchanged.

4 — Pad surfaces

Touch-first variant of the same tokens: 48px inputs and value-help buttons, 52px list rows, 56px scan action, keypad keys ≥ 52px. No new colors — the pad skin is the corporate system at larger hit areas.

5 — Agent UI

Chat surface in the same skin: user bubbles primary-50, agent bubbles on surface, status line 11px/500 muted with a primary spinner, streaming caret 2px primary. No glow effects, no neon — the working state reads through motion, not color.
